# 169. Majority Element

- 링크: https://leetcode.com/problems/majority-element/
- 유형: hash (개수 세기). 정렬로도 풀 수 있다
- 날짜: 2026-10-21
- 상태: 혼자 풂

## 접근

`HashMap`으로 숫자별 등장 횟수를 센 뒤, 키를 돌면서 횟수가 `n / 2`보다 큰 숫자를 반환한다.
문제에서 과반수 원소가 항상 있다고 보장하므로 마지막 `return 0`에는 도달하지 않는다.

## 시간복잡도 / 공간복잡도

- 시간: O(n)
- 공간: O(n)  (서로 다른 숫자 수만큼 맵에 저장)

## 다른 풀이

- **정렬**: 과반수 원소는 정렬하면 반드시 가운데를 지나므로 `Arrays.sort(nums); return nums[nums.length / 2];` 시간 O(n log n), 추가 공간은 거의 없음.
- **보이어-무어 투표**: 후보와 카운트 하나만 들고 다니며, 같은 수면 +1, 다른 수면 -1, 0이 되면 후보를 바꾼다. 과반수는 다른 수들과 서로 상쇄해도 끝까지 남는다. 시간 O(n), 공간 O(1). 문제의 follow-up(선형 시간 + O(1) 공간)이 이 방법을 묻는다.

## 막혔던 점

- 없음. 해시로 개수를 세는 패턴(`getOrDefault(키, 0) + 1`)을 그대로 썼다.
