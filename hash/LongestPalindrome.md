# 409. Longest Palindrome

- 링크: https://leetcode.com/problems/longest-palindrome/
- 유형: 해시 (글자별 개수 세기)
- 날짜: 2026-10-21
- 상태: 혼자 풀어서 통과

## 접근

만들 수 있는 가장 긴 팰린드롬의 **길이**만 구하면 된다. 순서는 상관없다.
`HashMap`으로 글자별 개수를 센다. 짝수 개인 글자는 전부 쓰고, 홀수 개인 글자는 하나를 빼고(짝수 개만큼) 쓴다.
홀수 개인 글자가 하나라도 있었으면, 그중 한 글자를 가운데에 놓을 수 있으므로 +1 한다.

## 시간복잡도 / 공간복잡도

- 시간: O(n)
- 공간: O(1)  (영문 대소문자뿐이라 키가 최대 52개)

## 막혔던 점

- 가운데에는 **한 글자만** 올 수 있다. 홀수 개인 글자가 여러 개여도 +1은 한 번만 한다. 그래서 `flag`를 더하지 않고 1로 덮어쓴다.
  - 예: `"aaabbbccc"` → 2 + 2 + 2 + 1 = 7
- 대소문자는 다른 글자다(`"Aa"` → 1).
- 코드의 `if (s.length() == 1) return 1;`은 없어도 아래 로직이 1을 돌려준다. 이렇게 특수 처리 없이도 맞는지 먼저 확인하는 습관을 들이자.
