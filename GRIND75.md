# Grind 75 진행 목록

공부한 주제 기준으로 **지금 풀 수 있는 문제**와 **나중에 풀 문제**를 나눈 목록이다.

- 기준 시점: `algorithm-notes`의 00 시간복잡도, 01 해시, 02 스택/큐, 03 정렬까지 공부함
- 진행: 완료 18 / 75, 지금 풀 수 있음 21

## 쓰는 방법

1. "지금 풀 수 있는 문제"는 **유형을 섞어서** 순서를 정해두었다. 위에서부터 풀지 않아도 된다.
2. 풀기 전에 5분 동안 적는다: 입력 크기 / 핵심 문장(단서) / 후보 알고리즘 2개와 시간복잡도 / 선택과 근거
3. 풀고 나서 맨 아래 "정답표"를 펼쳐 내 예상과 비교한다. 틀렸으면 그 단서를 노트에 남긴다.
4. 다 풀면 상태를 `완료`로 바꾸고 풀이 파일을 연결한다.
5. 새 주제 노트를 끝내면 "나중에 풀 문제"에서 그 주제 문제를 위 표로 옮긴다.
