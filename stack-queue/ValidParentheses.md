# 20. Valid Parentheses

- 링크: https://leetcode.com/problems/valid-parentheses/
- 유형: stack
- 날짜: 2026-10-21
- 상태: 접근(스택)과 뼈대를 설명받은 뒤 짝 확인 부분을 직접 작성해서 통과

## 접근

열린 괄호는 스택에 쌓는다. 닫는 괄호가 나오면 스택 맨 위(가장 최근에 열린 괄호)를 꺼내서 짝인지 확인한다.
스택이 비어 있는데 닫는 괄호가 나오거나, 짝이 아니면 `false`.
끝났을 때 스택이 비어 있어야 `true` (안 닫힌 괄호가 남으면 `false`).

## 시간복잡도 / 공간복잡도

- 시간: O(n)
- 공간: O(n)

## 막혔던 점 / 배운 점

- 프로그래머스 올바른 괄호는 종류가 하나라 카운터로 충분했지만, 이 문제는 종류가 세 가지라 개수만으로는 `"([)]"`를 걸러낼 수 없다. 어떤 괄호와 짝인지 기억해야 해서 스택이다.
- 닫는 괄호에서 `pop()` 전에 `isEmpty()`를 확인하지 않으면 `")"`에서 `NoSuchElementException`이 난다.
- 마지막에 `stack.isEmpty()`를 반환해야 `"("`처럼 열린 괄호가 남은 경우를 걸러낸다.
- 짝 확인은 `if` 세 개 대신 `Map<Character, Character>`(`')' → '('` 등)로 할 수도 있다.
- 길이가 홀수면 짝이 맞을 수 없어서 바로 `false`를 반환할 수 있다 (선택).

## 재풀이 기록 (2026-11-08)

- 결과: ○ (힌트 없이 혼자 통과)
- 스택 쌓기, `pop()` 전 `isEmpty()` 확인, 마지막 `stack.isEmpty()` 확인 세 가지를 모두 처음부터 넣음. 지난번에 설명받았던 부분이 이번엔 다 기억남.
- 다듬을 점 (정답과는 무관):
  - `s.charAt(i)`를 여러 번 쓰는 대신 `char ch = s.charAt(i);`로 한 번만 꺼내면 읽기 쉽다.
  - `if (stack.isEmpty()) return true; else return false;`는 `return stack.isEmpty();` 한 줄로 줄일 수 있다.
