# 100. Same Tree

- 링크: https://leetcode.com/problems/same-tree/
- 유형: tree, 재귀 (DFS)
- 날짜: 2026-11-25
- 상태: 풀이 확인 후 풂 (힌트 두 번 받고도 막혀서 완성 코드를 본 뒤 직접 작성해 통과) · 재풀이 필요

## 접근

두 트리를 같은 방향으로 동시에 내려가면서 노드 한 쌍씩 비교한다.
- 각 호출은 **지금 노드 한 쌍(`p`, `q`)만** 확인하고 자식은 다음 호출에 맡긴다
- 확인 순서: 둘 다 null → true / 한쪽만 null → false / 값 다름 → false
- 마지막에 `왼쪽끼리 결과 && 오른쪽끼리 결과`를 반환

## 시간복잡도 / 공간복잡도

- 시간: O(n) (노드 한 쌍을 한 번씩 방문, n은 더 작은 트리의 노드 수)
- 공간: O(h) (재귀 호출 스택, h는 트리 높이. 한쪽으로 치우치면 O(n))

## 막혔던 점

- `p.next`를 쓰려고 함 → `next`는 `ListNode`의 필드. `TreeNode`는 `left`/`right`로 이동
- 종료 조건을 `p.left == null && q.right == null`로 씀 → 호출이 책임지는 건 자식이 아니라 **`p`, `q` 자신**. `p`가 null이면 `p.left`에서 NPE. null 확인은 `.val`을 읽기 전에, "둘 다 null → 한쪽만 null" 순서로
- `p.left == q.left`로 자식을 비교함 → 객체의 `==`는 같은 객체인지(참조) 비교라 서로 다른 트리에서는 둘 다 null일 때만 true. 자식이 같은지는 재귀 호출이 확인하고, 현재 단계에서는 `val`만 비교
- `checkTree(...)`를 호출만 하고 끝에 `return true` → 아래에서 나온 false가 버려짐. 재귀 결과는 `return A && B`로 이어서 위로 전달
- 트리 재귀의 틀: null 처리 → 현재 노드에서 할 일 → 왼쪽/오른쪽 재귀 결과 합치기
