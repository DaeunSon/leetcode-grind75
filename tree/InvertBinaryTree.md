# 226. Invert Binary Tree

- 링크: https://leetcode.com/problems/invert-binary-tree/
- 유형: tree / DFS (재귀)
- 날짜: 2026-11-11
- 상태: 104와 같은 모양이라는 설명 + 빈칸 뼈대를 본 뒤, 뼈대와 다른 방식(받을 때 이미 자리를 바꿈)으로 직접 써서 통과

## 접근

104의 네 줄 모양 그대로: 종료 조건(`null`이면 `null`) / 오른쪽 트리 뒤집어 받기 / 왼쪽 트리 뒤집어 받기 / **합치기 = 자리를 바꿔 달기**.
변수 이름을 **달 자리** 기준으로 지음: `left`에는 왼쪽에 달 트리(= 뒤집은 원래 오른쪽)를 받는다.
104는 숫자(깊이)를 돌려받았고, 이번엔 트리(뒤집힌 트리의 루트)를 돌려받아서 반환형이 `TreeNode`.

## 시간복잡도 / 공간복잡도

- 시간: O(n)
- 공간: O(h) (재귀 호출 스택, h는 트리 높이)

## 막혔던 점

- "변수 없이 `root.left = invertTree(root.right); root.right = invertTree(root.left);`로 쓰면?"에 답하지 못함
  - 첫 줄이 `root.left`를 덮어써서 원래 왼쪽 트리 `[2,1,3]`을 아무도 안 가리킴 (잃어버림)
  - 둘째 줄의 `root.left`는 이미 뒤집은 오른쪽 트리라서, 그걸 또 뒤집어 원래대로 돌려 놓음
  - 결과: 양쪽 자식이 같은 노드(안 뒤집힌 `[7,6,9]`)
- 206의 `next` 저장과 같은 규칙: **값을 덮어쓰기 전에, 원래 값이 나중에 또 필요하면 먼저 변수에 저장한다**
