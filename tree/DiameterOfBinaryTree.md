# 543. Diameter of Binary Tree

- 링크: https://leetcode.com/problems/diameter-of-binary-tree/
- 유형: tree, 재귀 (DFS 후위 순회)
- 날짜: 2026-11-26
- 상태: 힌트 받고 풂 (처음엔 트리 높이만 반환. 재귀 실행 순서 설명을 듣고, "답 후보는 `left + right`, 모든 노드 중 최댓값"을 힌트로 받아 직접 고쳐 완성) · 재풀이 필요

## 접근

모든 경로에는 꺾이는 꼭대기 노드가 하나 있다. 꼭대기를 한 노드로 정하면 가장 긴 경로는 왼쪽으로 가장 깊이 + 오른쪽으로 가장 깊이 내려간 것이다. 깊이는 자식의 결과가 있어야 알 수 있으므로 후위 순회(왼쪽 → 오른쪽 → 현재 노드)로 푼다.
- 재귀 함수 `getMaxLength`는 그 노드에서 아래로 가장 깊이 내려가는 길의 노드 수를 반환한다. `null`이면 0
- 각 노드에서 `left_len + right_len`이 "이 노드에서 꺾이는 가장 긴 경로"의 간선 수다
- 어느 노드가 꼭대기일 때 가장 긴지 모르므로 필드 `len`에 모든 노드의 후보 중 최댓값을 기록한다
- 부모에게는 한쪽 길만 이어 줄 수 있으므로 `max(left_len, right_len) + 1`을 반환한다

## 시간복잡도 / 공간복잡도

- 시간: O(n) (노드를 한 번씩 방문)
- 공간: O(h) (재귀 호출 스택, h는 트리 높이. 한쪽으로 치우치면 O(n))

## 막혔던 점

- 처음엔 `max(left+1, right+1)`만 반환해 트리 높이를 답으로 냄 (`[1,2]`에서 1이 아니라 2) → 부모에게 돌려주는 값(아래로 내려가는 깊이)과 답으로 기록하는 값(`left + right`)은 다르다. return은 하나뿐이니 답은 필드에 따로 기록
- `len = left_len + right_len`으로 덮어씀 → 마지막에 끝나는 루트의 값만 남는다. 가장 긴 경로가 루트를 지나지 않으면 틀림 (`[1,2,null,3,4,5,null,null,6]`: 정답 4, 덮어쓰면 3). `Math.max(len, ...)`로 최댓값만 남기기
- 재귀 실행 순서가 그려지지 않음 ("right 호출이 실행된다고 위로 올라가진 않는데?") → 위로 올라가는 건 `return`을 만났을 때이고, 호출한 줄로 돌아가 다음 줄부터 이어진다. 노드마다 "왼쪽 끝남 → 오른쪽 끝남 → return"
- 순회 이름을 중위라고 적음 (코드 주석) → 자식 둘의 결과를 받은 뒤 현재 노드를 계산하므로 후위 순회
- 스터디원 질문 "`len`에는 무엇이 저장되나"에 "꼭대기에서 어떤 위치까지의 최대 길이"라고 답함 → 꼭대기에서 한쪽으로 내려가는 길이는 return 값이다. `len`은 꼭대기를 지나 왼쪽 끝에서 오른쪽 끝까지 잇는 경로(`left + right`)의 최댓값
- `left + right`가 왜 답인지는 풀고 나서도 바로 이해되지 않았음 → 재풀이 때 작은 트리로 노드별 `left + right` 표를 직접 그려 보기
