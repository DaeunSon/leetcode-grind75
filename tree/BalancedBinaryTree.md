# 110. Balanced Binary Tree

- 링크: https://leetcode.com/problems/balanced-binary-tree/
- 유형: tree, 재귀 (DFS 후위 순회)
- 날짜: 2026-11-26
- 상태: 힌트 받고 풂 (접근과 `-1` 검사 한 줄을 힌트로 받아 직접 작성해 통과. 재귀 실행 순서는 아직 이해 안 됨) · 재풀이 필요

## 접근

높이는 자식의 결과가 있어야 부모에서 계산할 수 있으므로 후위 순회(왼쪽 → 오른쪽 → 현재 노드)로 푼다.
- 재귀 함수 `height`는 서브트리의 높이를 반환한다. `null`이면 0
- 왼쪽·오른쪽 높이 차가 1보다 크면 높이 대신 `-1`(불균형 신호)을 반환한다
- 자식이 `-1`을 돌려줬으면 계산하지 않고 `-1`을 그대로 위로 전달한다
- `isBalanced`는 `height(root) != -1`만 확인한다

## 시간복잡도 / 공간복잡도

- 시간: O(n) (노드를 한 번씩 방문)
- 공간: O(h) (재귀 호출 스택, h는 트리 높이. 한쪽으로 치우치면 O(n))

## 막혔던 점

- BFS 큐로 풀려고 함 → 높이는 아래에서 위로 올라오는 정보라 위에서 아래로 가는 BFS로는 알 수 없다. "자식 결과로 부모를 계산"하면 후위 순회
- 자식의 `-1` 검사를 빼먹음 → `-1`은 높이가 아니라 신호인데 뺄셈에 넣으면 `|-1 - 0| = 1`로 통과해 불균형이 사라진다 (왼쪽으로만 뻗은 `1 → 2 → 3 → 4`에서 `true`가 나옴). 차이를 계산하기 **전에** `-1`인지 먼저 확인
- 재귀 함수의 실행 순서가 머릿속에 그려지지 않음 → 작은 트리로 호출과 반환을 손으로 따라가 보기
