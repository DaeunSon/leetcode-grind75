# 67. Add Binary

- 링크: https://leetcode.com/problems/add-binary/
- 유형: 구현 (뒤에서부터 한 자리씩 더하고 자리올림)
- 날짜: 2026-10-21
- 상태: 흐름을 설명받은 뒤 작성, 디버깅 후 통과. **꼭 재풀이** (프로그래머스 이진수 더하기와 같은 문제인데 같은 곳에서 다시 막힘)

## 접근

손으로 하는 세로 덧셈을 그대로 옮긴다.
`a`, `b`의 끝에 인덱스 `i`, `j`를 두고 한 자리씩 왼쪽으로 이동한다.
`sum = 올림 + a의 자리 + b의 자리`(끝난 쪽은 0), 이 자리에 쓸 값은 `sum % 2`, 다음 올림은 `sum / 2`.
`a`, `b`가 남았거나 올림이 남은 동안 반복하고, 뒤에서부터 쌓았으므로 마지막에 뒤집는다.

## 시간복잡도 / 공간복잡도

- 시간: O(max(n, m))
- 공간: O(max(n, m))  (결과 문자열)

## 막혔던 점

- 어떤 자료구조/알고리즘을 쓸지 감이 안 왔다. 이 문제는 이름 붙은 알고리즘이 없는 **구현 문제**다. 사람이 손으로 푸는 순서를 먼저 적으면 그대로 코드가 된다.
- 숫자로 바꿔서 더하면(`Integer.parseInt(a, 2)`) 길이가 길 때 `int`, `long`을 넘는다. 한 자리씩 더해야 한다.
- 포인터는 지금 보고 있는 위치를 담은 인덱스 변수다. 두 문자열 위치가 따로 필요하고, 다 읽은 뒤에도 올림이 남을 수 있어서 `for`보다 `while (i >= 0 || j >= 0 || carry > 0)`이 맞다.
- 처음 코드에서 막힌 3가지
  - 한쪽이 먼저 끝나도 `charAt(i--)`를 불러서 `charAt(-1)` → `if (i >= 0)`, `if (j >= 0)`로 남아 있을 때만 더한다.
  - `sum`(0~3)을 그대로 붙였다 → 이 자리 값은 `sum % 2`, 올림은 `sum / 2` (몫과 나머지는 한 쌍).
  - 뒤에서부터 붙여서 순서가 거꾸로 → `StringBuilder`에 쌓고 `reverse()`.

## 재풀이할 때 확인

- [ ] `"11"` + `"1"` = `"100"` (길이 차이, 마지막 올림, 뒤집기)
- [ ] `"1"` + `"1"` = `"10"` (마지막 올림)
- [ ] `"0"` + `"0"` = `"0"`
- [ ] `while` 조건의 세 가지와 `if (i >= 0)`가 왜 필요한지 말로 설명할 수 있다
